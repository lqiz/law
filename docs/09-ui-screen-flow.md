## 2. 路由表

```dart
// go_router 路由定义
final router = GoRouter(
  initialLocation: '/lock',
  routes: [
    GoRoute(path: '/lock',                builder: (_, __) => LockScreen()),
    GoRoute(path: '/pin-setup',           builder: (_, __) => PinSetupScreen()),
    GoRoute(path: '/home',                builder: (_, __) => HomeScreen()),
    GoRoute(path: '/case/:caseId',        builder: (_, s) => CaseDetailScreen(caseId: s.pathParameters['caseId']!)),
    GoRoute(path: '/case/:caseId/capture/:mode', builder: ...),  // mode: camera|audio|import
    GoRoute(path: '/case/:caseId/evidence/:evidenceId', builder: ...),
    GoRoute(path: '/case/:caseId/export',  builder: ...),
    GoRoute(path: '/guide',               builder: (_, __) => GuideListScreen()),
    GoRoute(path: '/guide/:scenario',     builder: ...),
    GoRoute(path: '/settings',            builder: (_, __) => SettingsScreen()),
    GoRoute(path: '/settings/security',   builder: ...),
  ],
);
```

## 4. 全局交互规则

### 4.1 防截屏

```
以下页面启用防截屏:
  - EvidenceDetailScreen（证据查看时明文可见）
  - CaptureScreen 的固化结果页（含哈希值）
  - ExportScreen 导出完成页（含包哈希值）
  - LockScreen（防止旁人看到 PIN 输入）

以下页面不防截屏:
  - HomeScreen（案件名称无敏感信息）
  - GuideScreen（公开引导内容）
  - SettingsScreen
```

### 4.2 后台切换

```
App 进入后台（home 键 / 切换应用）:
  → 如果在 EvidenceDetailScreen: 立即擦除临时解密文件
  → 如果在录音中: 继续录音（后台录音权限）
  → 如果在其他页面: 无特殊处理

App 从后台恢复:
  → 如果超过 5 分钟: 要求重新解锁（PIN/生物识别）
  → 如果未超时: 直接恢复
```

### 4.3 通知与反馈

```
固化成功: 本地通知 "E001 证据已固化 ✓"
TSA 补戳成功: 本地通知 "E003 时间戳已获取"
完整性异常: 醒目红色警告 "⚠ E002 完整性校验失败，请勿删除原文件"
导出完成: 本地通知 "证据包已生成"
```
